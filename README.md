# ButtonMatrix Control – julkaisut

Valmiit Windows-buildit ButtonMatrix CherryMX RGB -laitteen ohjelmaan. Lähdekoodi on yksityinen.

- **Asennus:** lataa uusimmasta releasesta `ButtonMatrix-Setup-<versio>.exe` ja aja se. Ei vaadi ylläpitäjän oikeuksia; luo Käynnistä-valikon ja halutessa työpöydän pikakuvakkeen.
- **Ilman asennusta:** `ButtonMatrix-Control-<versio>.zip` – pura samaan kansioon ja käynnistä `ButtonMatrix Control.exe`.
- **Päivitykset:** sovellus päivittää itsensä automaattisesti tästä reposta (`version.json` + SHA-256-tarkistus).
