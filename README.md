# ButtonMatrix Control – julkaisut

Valmiit Windows-buildit ButtonMatrix CherryMX RGB -laitteen ohjelmaan. Lähdekoodi on yksityinen.

- **Ensiasennus:** lataa uusimmasta releasesta `ButtonMatrix-Control-<versio>.zip`, pura samaan kansioon ja käynnistä `ButtonMatrix Control.exe`.
- **Päivitykset:** sovellus päivittää itsensä automaattisesti tästä reposta (`version.json` + SHA-256-tarkistus).
